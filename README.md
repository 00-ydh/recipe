# 🍳 냉부 (레시피 & 요리 꿀팁 공유 플랫폼)

> 사용자들이 자신만의 레시피와 유용한 요리 꿀팁을 공유하고, 서로 팔로우하며 소통할 수 있는 커뮤니티 웹 서비스입니다.

---

## 프로젝트 기간
- **개발 기간**: 2026.07.24 ~ 2026.08.06
- **참여 인원**: 백엔드 유동훈, 이유림, 이지원, 최원일

---

##  Tech Stack (기술 스택)
- **Backend**: Java, Spring Boot, JDBC
- **Frontend**: HTML5, CSS3, Thymeleaf, JavaScript
- **Database**: MySQL
- **Version Control**: Git, GitHub

---

## 주요 기능 (Key Features)
1. **회원 관리**
    - 회원가입, 로그인, 비밀번호 찾기, 회원정보 수정 및 회원 탈퇴
2. **레시피 게시판**
    - 레시피 등록, 수정, 삭제 및 상세 조회 (최신순/조회순 정렬)
    - 스크랩(즐겨찾기) 및 좋아요(추천) 기능
    - 댓글 작성 및 관리
3. **요리 꿀팁 게시판**
    - 나만의 꿀팁 등록, 수정, 삭제 및 상세 조회 (최신순/조회순 정렬)
4. **마이페이지 & 소셜(팔로우)**
    - 내가 쓴 글 및 스크랩한 레시피 모아보기
    - 다른 사용자의 프로필 방문 및 팔로우/언팔로우 기능
    - 팔로우한 유저들의 최신 레시피를 모아보는 '팔로우 피드' 제공
5. **오늘 뭐 먹지?**
    - 카테고리별 랜덤 레시피 추천 기능

---

## Database 구조 (ERD)
> `member`, `category`, `post`, `reply`, `good`, `follow` 테이블 구조로 설계되었습니다.
