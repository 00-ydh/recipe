## 1. 서비스 화면 구성 개요

### 1.1 주요 화면 목록
- 메인 화면 / 게시글 목록 (GET `/posts`)
- 게시글 상세 조회 (GET `/posts/{postId}`)
- 게시글 작성 (GET `/posts/form`)
- 게시글 수정 (GET `/posts/{postId}/form`)
- 사용자 회원가입 (GET `/signup`)
- 사용자 로그인 (GET `/login`)

## 2. 주요 화면별 명세

### 2.1 게시글 목록 화면 (GET `/posts`)
<img src="../images/01_post_list.png" width="500" alt="메인 페이지 화면">

- 출력 데이터 항목 (Output Data):
    - GNB 영역: 서비스 로고 
    - 검색어 입력 폼 
    - 회원 인증 상태 정보
        - 비로그인시: 로그인 버튼
        - 로그인시: MY 셀렉트 박스(클릭 시 마이페이지 이동/ 내 정보수정/ 로그아웃)
    - 레시피 등록 버튼
    - 레시피 목록 버튼
    - 오늘 뭐 먹지 버튼
    - 요리꿀팁 목록 버튼
    - 목록 테이블: 게시글 번호, 제목, 작성자, 작성일시, 조회수
    - 명예의 전당 영역
        - 기간 제한 없이 전체 기간 중 추천수가 가장 높은 레시피 목록
    - 밥플루언서 영역
        - 팔로워 수를 가장 많이 보유한 추천 회원 프로필 목록
    - 이달의 추천 레시피 영역:
        - 최근 한 달 기간 내 추천수가 가장 높은 게시글 (최대 6개)
    - 최신 요리 꿀팁 영역
        - 최신순으로 정렬된 요리꿀팁 게시글(최대 5개)
    - 하단 영역
        - 푸터 정보
- 화면 제어 및 권한 규칙 (Behavior Rules):
    - 서비스 로고 클릭 시 게시글 목록 화면으로 이동
    - 검색어 입력 및 제출 시 조건별 게시글 목록 검색 조회
    - 비로그인 상태: login버튼 클릭 시 로그인 페이지로 이동
    - 로그인상태: my메뉴(내 정보 수정, 페이지 이동, 로그아웃 기능 지원)과 레시피 등록 버튼이 활성화
    - 메인 메뉴 탭(레시피, 오늘 뭐 먹지, 요리꿀팁) 클릭 시 해당 게시판 목록 페이지로 이동
    - 명예의 전당 사진 클릭 시 해당 레시피 상세 페이지로 이동
    - 밥플루언서 프로필 클릭 시 해당 회원의 프로필로 이동
    - 이달의 추천 레시피 영역의 사진 클릭시 레시피 상세 페이지로 이동
    - 요리꿀팁 게시글 클릭 시 해당 꿀팁 게시글 상세 페이지로 이동
### 2.2 게시글 상세 화면 (GET `/posts/{postId}`)
<img src="../images/02_post_detail.png" width="500" alt="게시글 상세 화면">

- 출력 데이터 항목 (Output Data):
    - 상단 영역: 게시글 제목, 작성자 닉네임, 작성일시, 조회수
    - 본문 영역: 게시글 본문 텍스트 콘텐츠
    - 댓글 영역: 댓글 작성자, 작성일시, 댓글 내용 목록 및 댓글 작성 폼
- 화면 제어 및 권한 규칙 (Behavior Rules):
    - 게시글 작성자 본인 인증 시에만 수정 및 삭제 버튼 노출
    - 댓글 작성자 본인 인증 시에만 댓글 삭제 버튼 노출
    - 목록 버튼 클릭 시 게시글 목록 화면으로 이동

### 2.3 게시글 작성 화면 (GET `/posts/form`)
<img src="../images/03_post_form.png" width="500" alt="게시글 작성 화면">

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
    - 제목: 필수 입력 항목, 공백 제출 제한, 최대 100자 이하
    - 본문: 필수 입력 항목, 공백 제출 제한
- 화면 제어 및 권한 규칙 (Behavior Rules):
    - 로그인 인증 세션 존재시에만 접근 허용 (미인증 시 로그인 화면 이동)
    - 취소 버튼 클릭 시 이전 목록 화면으로 이동
    - 저장 버튼 제출 시 유효성 검증 후 게시글 등록 처리

### 2.4 게시글 수정 화면 (GET `/posts/{postId}/form`)
<img src="../images/03_post_form.png" width="500" alt="게시글 수정 화면">

- 출력 데이터 항목 (Output Data):
    - 기존 작성된 게시글 제목 및 본문 텍스트 데이터 로딩
- 입력 데이터 및 검증 규칙 (Input Data & Validation):
    - 제목: 필수 입력 항목, 공백 제출 제한, 최대 100자 이하
    - 본문: 필수 입력 항목, 공백 제출 제한
- 화면 제어 및 권한 규칙 (Behavior Rules):
    - 게시글 작성자 본인 인증 세션 확인 후 수정 권한 부여
    - 수정 완료 제출 시 유효성 검증 수행 후 상세 화면으로 이동

### 2.5 사용자 회원가입 화면 (GET `/signup`)
<img src="../images/04_signup.png" width="500" alt="사용자 회원가입 화면">

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
    - 아이디: 필수 입력 항목, 영문/숫자 조합 4~20자 이하, 중복 불가
    - 비밀번호: 필수 입력 항목, 8자 이상
    - 닉네임: 필수 입력 항목, 최대 20자 이하
    - 이메일: 필수 입력 항목, 이메일 형식 검증
- 화면 제어 및 권한 규칙 (Behavior Rules):
    - 회원가입 완료 제출 시 유효성 검증 수행 후 로그인 화면으로 이동

### 2.6 사용자 로그인 화면 (GET `/login`)
<img src="../images/05_login.png" width="500" alt="사용자 로그인 화면">

- 입력 데이터 및 검증 규칙 (Input Data & Validation):
    - 아이디: 필수 입력 항목
    - 비밀번호: 필수 입력 항목
- 화면 제어 및 권한 규칙 (Behavior Rules):
    - 로그인 성공 시 메인 게시글 목록 화면으로 이동
    - 인증 실패 시 로그인 실패 오류 메시지 출력
    - 회원가입 링크 클릭 시 회원가입 화면으로 이동
