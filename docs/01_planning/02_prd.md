## 1.1 메인페이지 기능

| 요구사항 ID     | 구분    | 기능명         | 담당자 | 우선순위 | 상세 내용                              |
|:------------|:------|:------------|:----|:-----|:-----------------------------------|
| REQ-MAIN-01 | 메인페이지 | 탭별 페이지 이동   | 미정  | 3순위  | 추천, 분류 탭 메뉴 구성 및 탭 클릭 시 해당 페이지로 이동 |
| REQ-MAIN-02 | 메인페이지 | 상단 검색 기능    | 미정  | 2순위  | 상단에 검색창 제공                         |
| REQ-MAIN-03 | 메인페이지 | 추천 순 정렬     | 미정  | 2순위  | 추천 높은 순으로 정렬, 최대 10개, 한 달 기간 내 기준  |
| REQ-MAIN-04 | 메인페이지 | 카테고리 검색     | 미정  | 2순위 | 분류 탭에서 카테고리를 선택하여 해당 카테고리의 내용을 조회  |
| REQ-MAIN-05 | 메인페이지 | 최근 본 래시피 정렬 | 미정  | 2순위 | 최근 본 래시피 정렬, 최대 4~5개정도             |

## 1.2 회원 기능

| 요구사항 ID      | 구분 | 기능명      | 담당자 | 우선순위 | 상세 내용                                          |
|:-------------| :--- |:---------|:----| :--- |:-----------------------------------------------|
| REQ-USER-01  | 회원 | 회원가입      | 미정  | 1순위 | 이메일, 비밀번호, 이름, 전화번호,별명 입력 받아 member DB 테이블에 저장 |
| REQ-USER-02  | 회원 | 로그인/로그아웃  | 미정  | 1순위 | 이메일/비밀번호 DB 검증 후 HttpSession 생성 및 파기           |
| REQ-USER-03  | 회원 | 회원정보      | 미정  | 1순위 | 이메일, 비밀번호, 이름, 전화번호 정보 조회                      |

## 1.3 게시글 기능

| 요구사항 ID      | 구분 | 기능명          | 담당자 | 우선순위 | 상세 내용                                       |
|:-------------| :--- |:-------------|:----| :--- |:--------------------------------------------|
| REQ-POST-01  | 게시글 | 게시판 목록조회     | 미정  | 1순위 | 전체 질문 게시글 목록 표시 및 상세 이동 (post 테이블 조회)       |
| REQ-POST-02  | 게시글 | 게시판 작성       | 미정  | 1순위 | 선택할 수 있는 카테고리(종류,재료,인원,요리시간) 데이터를 받아 등록     |
| REQ-POST-03  | 게시글 | 게시판 상세 조회    | 미정  | 1순위 | 게시글에서 작성하고 등록한 데이터 상세 조회                    |
| REQ-POST-04  | 게시글 | 페이징 및 키워드 검색 | 미정  | 2순위 | 게시글 목록 페이지당 10개 페이징 처리 및 질문 제목/내용 검색 기능     |

## 1.4 댓글 기능

| 요구사항 ID      | 구분 | 기능명      | 담당자 | 우선순위 | 상세 내용                                    |
|:-------------| :--- |:---------|:----| :--- |:-----------------------------------------|
| REQ-REPLY-01 | 댓글 | 답변 댓글 작성  | 미정  | 2순위 | 질문 상세 페이지 하단 폼에서 답변 내용 입력 및 reply 테이블 저장 |
| REQ-REPLY-02 | 댓글 | 답변 댓글 삭제  | 미정  | 2순위 | 본인 작성 답변 댓글 세션 확인 후 삭제 처리                |
| REQ-REPLY-03 | 댓글 | 답변 댓글 수정  | 미정  | 3순위 | 본인 작성 답변 댓글 세션 확인 후 내용 수정 폼 제공 및 반영      |
