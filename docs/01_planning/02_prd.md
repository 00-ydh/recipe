## 1.1 메인페이지 기능

| 요구사항 ID     | 구분    | 기능명         | 담당자 | 우선순위 | 상세 내용                             |
|:------------|:------|:------------|:----|:-----|:----------------------------------|
| REQ-MAIN-01 | 메인페이지 | 탭별 페이지 이동   | 미정  | 1순위  | 탭 메뉴 구성 및 탭 클릭 시 해당 페이지로 이동       |
| REQ-MAIN-02 | 메인페이지 | 상단 검색 기능    | 미정  | 1순위  | 상단에 검색창 제공                        |
| REQ-MAIN-03 | 메인페이지 | 추천 순 정렬     | 미정  | 2순위  | 추천 높은 순으로 정렬, 최대 10개, 한 달 기간 내 기준 |
| REQ-MAIN-04 | 메인페이지 | 카테고리 검색     | 미정  | 1순위  | 분류 탭에서 카테고리를 선택하여 해당 카테고리의 내용을 조회 |
| REQ-MAIN-05 | 메인페이지 | 최근 본 래시피 정렬 | 미정  | 2순위  | 최근 본 래시피 정렬, 최대 4~5개정도            |
| REQ-MAIN-06 | 메인페이지 | 밥플루언서       | 미정  | 3순위  | 팔로우 많이 받은 계정을 밥플루언서로 선정하여 표시      |
| REQ-MAIN-07 | 메인페이지 | 명예의 전당      | 미정  | 2순위  | 기간 상관없이 추천 높은 순으로 정렬(최대 10개)      |
| REQ-MAIN-08 | 메인페이지 | 요리꿀팁        | 미정  | 2순위  | 요리꿀팁 게시글을 최신 순으로 정렬(최대 5개)        |

## 1.2 회원 기능

| 요구사항 ID     | 구분 | 기능명      | 담당자 | 우선순위 | 상세 내용                                          |
|:------------| :--- |:---------|:----|:-----|:-----------------------------------------------|
| REQ-USER-01 | 회원 | 회원가입     | 미정  | 1순위  | 이메일, 비밀번호, 이름, 전화번호,별명 입력 받아 member DB 테이블에 저장 |

| REQ-USER-03 | 회원 | 회원정보     | 미정  | 1순위  | 이메일, 비밀번호, 이름, 전화번호 정보 조회                      |
| REQ-USER-04 | 회원 | 프로필 사진   | 미정  | 3순위  | 프로필 사진 등록                                      |

## 1.3 게시글 기능
## 1.3.1 레시피

| 요구사항 ID     | 구분  | 기능명          | 담당자 | 우선순위 | 상세 내용                                   |
|:------------|:----|:-------------|:----| :--- |:----------------------------------------|
| REQ-POST-01 | 게시글 | 게시판 목록조회     | 미정  | 1순위 | 전체 질문 게시글 목록 표시 및 상세 이동 (post 테이블 조회)   |
| REQ-POST-02 | 게시글 | 게시판 작성       | 미정  | 1순위 | 선택할 수 있는 카테고리(종류,재료,인원,요리시간) 데이터를 받아 등록 |
| REQ-POST-03 | 게시글 | 게시판 상세 조회    | 미정  | 1순위 | 게시글에서 작성하고 등록한 데이터 상세 조회                |
| REQ-POST-04 | 게시글 | 페이징 및 키워드 검색 | 미정  | 2순위 | 게시글 목록 페이지당 10개 페이징 처리 및 질문 제목/내용 검색 기능 |
| REQ-POST-05 | 게시글 | 좋아요          | 미정  | 1순위 | 사용자가 게시글에 좋아요를 달 수 있는 기능                |
| REQ-POST-06 | 게시글 | 조회수          | 미정  | 1순위 | 해당 게시글을 조회한 수를 표시하는 기능                  |
| REQ-POST-07 | 게시글 | 스크랩          | 미정  | 1순위 | 사용자가 게시글을 스크랩할 수 있는 기능                  |
