## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
본 프로젝트는 이러한 요구를 반영하여 사용자 친화적인 요리 공유 커뮤니티 플랫폼을 구축하는 것을 목적으로 합니다. 사용자가 [사진 + 설명] 형태의 단계를 통해 누구나 쉽게 요리 순서를 작성하고 따라 할 수 있도록 구성하며, 최근 1개월간의 사용자 반응을 반영한 인기 레시피 정렬 및 카테고리 탐색 기능을 통해 검증된 요리 정보를 빠르게 찾을 수 있도록 돕습니다. 최종적으로는 회원 인증부터 레시피 등록, 사용자 간의 상호작용(댓글/좋아요)으로 이어지는 완성도 높은 웹 서비스를 구현하여, 누구나 부담 없이 요리 노하우를 나누는 활발한 커뮤니티 공간을 만드는 것을 목표로 합니다.

### 1.1.2 서비스 주요 특징
- 회원가입 및 HttpSession 기반 로그인/로그아웃 세션 인증 처리
- 레시피 게시글 작성, 상세 조회, 수정, 삭제(CRUD) 지원
- 댓글 작성, 삭제, 수정 기능 및 서버 사이드 렌더링(Thymeleaf) 동적 뷰 제공
- 최근 1개월간 추천순으로 정렬되는 메인화면
- 카테고리 별 검색 기능

## 1.2 주요 기능 요구사항

### 1.2.0 메인페이지 기능
- 탭별 페이지이동(메뉴구성 : 추천, 분류, 오늘 뭐 먹지)
- 상단에 검색기능
- 추천 높은 순으로 정렬 ( 최대 10개, 한달 기간 내에)
- 최근 본 래시피 정렬 (최대 4~5개 정렬)

### 1.2.1 회원 관리 기능
- 회원가입 (이메일, 비밀번호, 이름, 별명, 전화번호)
- 로그인 및 로그아웃 (HttpSession 세션 생성 및 파기)
- 마이페이지 회원 정보 조회 및 수정

### 1.2.2 래시피 관리 기능
- 기술 질문 래시피 목록 조회 (페이징 및 키워드 검색 포함)
- 기술 질문 래시피 상세 보기 (조회수 증가 처리)
- 래시피 작성, 수정, 삭제 (본인 작성 글 제어)

### 1.2.3 답변 댓글 관리 기능
- 기술 질문 상세 화면 내 답변 댓글 작성
- 답변 댓글 목록 조회 및 본인 댓글 삭제/수정

### 1.2.4 래시피 작성 기능
- 대표사진 등록
- 제목
- 요리 설명
- 카테고리 구현 ( 메인카테고리, 서브카테고리, 인원수, 요리시간 등)
- 재료정보(한번에 입력)
- 요리순서(사진+글)
- 완성사진
- 요리팁 / 주의사항

### 1.2.5 오늘 뭐 먹지 기능
- 오늘 뭐 먹지 메뉴 들어 갔을 때 추천 수가 일정 수 이상 되는거 보여주기 (카테고리 별 한개씩)
