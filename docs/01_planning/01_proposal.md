## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
본 프로젝트는 사용자 친화적인 요리 공유 커뮤니티 플랫폼을 구축하는 것을 목적으로 합니다. 사용자가 [사진 + 설명] 형태의 단계를 통해 누구나 쉽게 요리 순서를 작성하고 따라 할 수 있도록 구성하며, 최근 1개월간의 사용자 반응을 반영한 인기 레시피 정렬 및 카테고리 탐색 기능을 통해 검증된 요리 정보를 빠르게 찾을 수 있도록 돕습니다. 최종적으로는 회원 인증부터 레시피 등록, 사용자 간의 상호작용(댓글/좋아요)으로 이어지는 완성도 높은 웹 서비스를 구현하여, 누구나 부담 없이 요리 노하우를 나누는 활발한 커뮤니티 공간을 만드는 것을 목표로 합니다.

### 1.1.2 서비스 주요 특징
- 회원가입 및 HttpSession 기반 로그인/로그아웃 세션 인증 처리
- 레시피 게시글 작성, 상세 조회, 수정, 삭제(CRUD) 지원
- 댓글 작성, 삭제, 수정 기능  제공
- 최근 1개월간 추천순으로 정렬되는 메인화면
- 자신이 선호하는 계정 구독 기능
- 대표 카테고리를 선택하여 그것을 기반으로 레시피 추천

## 1.2 주요 기능 요구사항

### 1.2.0 메인페이지 기능
- 탭별 페이지이동(메뉴구성 : 홈, 레시피, 오늘 뭐 먹지, 요리꿀팁)
- 상단에 검색기능
- 명예의 전당 (기간 없이 추천 제일 높은 순)
- 이달의 추천 레시피 (한달 기간 내에 추천 높은 순으로)
- 밥플루언서 최대 10명까지 프로필 표시
- 최신 요리 꿀팁

### 1.2.1 회원 관리 기능
- 회원가입 (이메일, 비밀번호, 이름, 별명, 전화번호)
- 로그인 및 로그아웃 (HttpSession 세션 생성 및 파기)
- 비밀번호 검사
- 아이디 이메일 중복검사
- 마이페이지 회원 정보 조회 및 수정
- 타 회원 프로필 조회
- 인터셉터 적용(로그인페이지로 자동 리다이렉트)

### 1.2.2 레시피 관리 기능
- 레시피 목록 조회 (페이징 및 키워드 검색 포함)
- 레시피 상세 보기 (조회수 증가 처리)
- 레시피 작성, 수정, 삭제 (본인 작성 글 제어)


### 1.2.3 답변 댓글 관리 기능
- 상세 화면 내 답변 댓글 작성
- 답변 댓글 목록 조회 및 본인 댓글 삭제

### 1.2.4 레시피 작성 기능
- 대표사진 등록
- 웹 에디터를 통한 본문 작성
- 카테고리 구현 (일식, 양식, 중식, 한식)
- 재료정보(한번에 입력)
- 쿠키를 통한 조회수 중복 방지

### 1.2.5 오늘 뭐 먹지 기능
- 오늘 뭐 먹지 메뉴 들어 갔을 때 추천 수가 일정 수 이상 되는거 보여주기 (카테고리 별 한개씩)


### 1.2.6 밥플루언서 기능
- 팔로우 많이 받은 계정을 밥플루언서로 선정하여 메인페이지에 표시
- 프로필 클릭 시 계정에 관한 정보, 레시피 나열

### 1.2.7 요리꿀팁 기능
- 요리꿀팁 게시글 목록 조회 (페이징 및 키워드 검색 포함)
- 요리꿀팁 게시글 상세 보기 (조회수 증가 처리)
- 요리꿀팁 게시글 작성, 수정, 삭제 (본인 작성 글 제어)

### 1.2.8 요리 꿀팁 작성 기능
- 제목 작성
- 웹 에디터를 통한 본문 작성

### 1.2.9 마이페이지 기능
- 내가 쓴 레시피,내가 쓴 꿀팁, 스크랩한 레시피, 스크랩한 꿀팁, 팔로우 목록 조회

### 1.2.10 검색기능
- 사용자가 입력한 키워드를 바탕으로 게시글 조회(페이징 적용)

### 1.2.11 좋아요 기능
-사용자가 좋아요 클릭시 좋아요 수 증가

### 1.2.11 스크랩 기능
-사용자가 스크랩 클릭시 마이페이지에서 조회 가능

### 1.3.2 팀 컨밴션
- 모든 작업은 브랜치 기반으로 진행하며 main 브랜치에 직접 push 하지 않는다.
- 작업 시작 전 최신 dev 브랜치를 pull 한다.
- 기능 단위로 작업을 나누고 PR을 통해 코드 리뷰 후 병합한다.
- 기술적 의견이 다를 경우 근거 기반으로 논의 후 다수결로 결정한다.
- 변수 명은 통일한다.
- 주석을 다 달도록 한다.
- 커밋 규칙을 준수한다.
- 결석, 지각 시 전 날에 미리 공유한다.
